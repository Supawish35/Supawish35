### <img src="https://api.iconify.design/lucide/user.svg?color=%2338bdf8" width="20" height="20" valign="middle" alt="user" /> About Me

I'm a Computer Science student at **Udon Thani Rajabhat University**, Thailand, working across full-stack development with a strong focus on backend systems and database architecture.

- **Stack in Practice:** Building web and desktop applications using **Node.js, Next.js, PHP, and C#**.
- **Databases & Systems:** Designing relational schemas with **PostgreSQL, MySQL, and SQL Server**, focusing on clean data modeling and practical system analysis.
- **Security & APIs:** Working with secure authentication workflows, REST APIs, and application security tools.
- **What Drives Me:** Turning system architectures and relational schemas into clean, reliable code that actually works in production.
